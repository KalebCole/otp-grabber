# OTP Grabber

OTP Grabber is a local-first macOS utility for copying recent verification
codes from Gmail and Messages. This repository is currently under
development.

## Development

The project uses Python's `unittest`, Node's built-in test runner, and Swift
Package Manager with XCTest. Run every harness with:

```sh
make test
```

Targeted commands are `make test-python`, `make test-js`, and
`make test-swift`.

See [PRODUCT.md](PRODUCT.md), [DESIGN.md](DESIGN.md), and
[specs/acceptance.md](specs/acceptance.md) for the approved product scope.
